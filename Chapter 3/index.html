    Introduction to Vue.js

    Why use a web framework?

    • Ease of development
    • Saves development time
    • Ease of maintenance
    • Abstraction of low-level functionality

    Presentation

    • Vue3 is the default version since February 2022 (Vue3 release date: January 2020 ).

    • Modern framework used on a large scale.

    • Lean and flexible front-end Framework.

    • Similar to related frameworks such as Angular and React.js.

    • Reactive : vue automatically tracks changes in JavaScript state and efficiently updates the DOM when changes occur.

    • Conditional rendering: (v-if, v-else, v-for … ).

    • Many developement tools : Vite, Vue-router, Vuex-Store, ESLint plugin …

    Comparison with Angular and ReactJs

    Single Page Application SPA

    • SPAs allows users to load a web page only once.

    • A separate update of the page rather than the entire page, which allows the user to interact much more dynamically.

    • Control the launch of new pages within the same domain, no more complete page refreshes are required.

    • UX improvement.

    Vue instance

    • In Vue.js, a "Vue instance" refers to a Vue application instance created using the Vue constructor.

    • A Vue instance is the entry point to any Vue.js application and represents the entire Vue application.

    • A view instance is created by passing options:
      1- el: the id of the HTML element to which we want to apply the view.
      2- data: the data to pass to the view.
      3- Methods: methods to call from the view
      4- Computed: these are methods that do not change results if they are called several times

    Single File Components - SFC

    • A world of components.

    • A component only depends on its internal data.

    • A component may contains sub-components.

    • Components are integrated in ".vue" SFC files.

    • A SFC file contains :
      1. The template (HTML) : content rendering
      2. Dynamic (JS) : content handling
      3. Style (CSS) : content styling (scoped or global)


    VITE

    • Vite is a fast and modern development tool created by Evan You, the creator of Vue.js, for building front-end web applications. It was designed to address some of the slowdowns encountered with tools like Webpack in complex JavaScript projects.

    • Vite is built to start the development server very quickly, even in large projects. This greatly enhances productivity, as developers no longer have to wait long for their projects to load or rebuild after each change.

    • Thanks to on-demand compilation, Vite offers extremely fast HMR (Hot Module Replacement), allowing developers to see the changes they make to their code instantly during development without losing the application's state.

    • To install the Vite tool, follow the steps below:

    • Install a server: We will install the Node.js server, which will be used in the next lab session. You can download it from the official Node.js website: Node.js — Download Node.js®.

    • Initialize a Vue project with Vite: After installing Node.js, open the command prompt (cmd), navigate to the directory where you want to create your project, and enter the following command to initialize a Vue project with Vite:

    1
    npm create vite@latest
    - It will ask you for the name of the project. Enter the name of your project (for example, vite-project).

    • Next, choose the framework to use. Select Vue and then choose JavaScript.


    Main elements of the project View :
    - "node_modules"  directory : all your project's dependencies, directly managed by "npm".
    - "src" directory: source code for your project (components, pages, etc.)
    - File "package.json" : your project's main configuration file.
    - File ".gitignore : contains the names of files/directories to be ignored when committing the project to Git.

    vue-router

    • Users need different URLs to distinguish one page from another.

    • Vue router allows components to be mapped to routes.

    • Access the vite-project project and install Vue router:

    1
2
    npm install vue-router
npm add vue-router

    1. Configure routes: path, name and component for each route in a index.js file.

    You need to create a router folder inside the src directory, then create the index.js file and set up the different routes.

    Here is an example of index.js for the / and /about routes:

    index.js

    // router/index.js
import { createRouter, createWebHistory } from 'vue-router';
import TestVue from '../components/TestVue.vue'; 
import AboutComponent from '../components/AboutComponent.vue'; 
const routes = [
{
path: '/',
name: 'TestVue',
component: TestVue 
},
{
path: '/about',
name: 'About',
component: AboutComponent 
}
];
const router = createRouter({
history: createWebHistory(import.meta.env.BASE_URL),
routes
});
export default router;

    2. Add and in the given page template:

    <router-link>: allows Vue-router to change the Url without reloading the page.

    <router-view>: allows Vue-router to display the contents of the URL (mapping component).

    • You can see the Official documentation of vue router
